# 🚻 Public Restroom Locator System

A web-based application to help users locate public restrooms nearby using real-time data, interactive maps, and community feedback. Built with accessibility and efficiency in mind, the system supports over 10,000 users and aims to improve public sanitation infrastructure.

### 🌐 [Live Demo](https://public-restroom-finder-eca7f.web.app/)

---

## 📌 Features

- 🔍 **Location-Based Search**  
  Find nearby public restrooms using GPS-enabled map integration.

- 🗺️ **Interactive Map Display**  
  View restrooms visually with location pins, details, and navigation links.

- 💬 **User Feedback System**  
  Share and view cleanliness ratings, helping maintain standards.

- 📱 **QR Code Scanning**  
  Easily access information by scanning QR codes at restroom locations.

- 🌍 **Multi-Language Support**  
  Ensures accessibility for users from diverse backgrounds.

- 🛠️ **Admin Dashboard**  
  Manage restroom entries, availability, and monitor user feedback.
